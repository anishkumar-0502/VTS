# Repository Overview

- **Name**: Trackify VTS App
- **Primary Language**: Dart (Flutter)
- **Structure Highlights**:
  - **FRONTEND/APP/trackify_vts/lib/**: Flutter application source code
  - **driver_app/features/dashboard/**: Driver dashboard feature modules
  - **core/Network/**: Networking utilities such as internet status notifier

- **Key Packages**: Flutter Material, GetX for state management/navigation

- **Build & Run**:
  1. Ensure Flutter SDK is installed and configured
  2. From project root run `flutter pub get`
  3. Launch with `flutter run`

- **Testing**: Run `flutter test`

- **Notable Patterns**:
  - Uses GetX dependency injection and navigation
  - Relies on ValueListenableBuilder for reactive UI updates
